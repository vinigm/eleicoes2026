        Para onde foram os eleitores de cada candidato

        Estimativa estatística. O voto é secreto: o que se observa são os totais de cada município nos dois turnos, e o modelo deduz o comportamento de cada grupo de eleitores a partir das diferenças entre os 5.571 municípios brasileiros.

        Como ler esta seção
        • É uma estimativa, não uma contagem de votos.
        • O modelo supõe que, dentro de cada região, um grupo de eleitores se comporta do mesmo jeito em todos os municípios. Quando isso não é verdade, surge um erro que as faixas de incerteza não mostram.
        • Para medir esse risco, o cálculo foi refeito com três modelos diferentes. Destacamos o que se mantém nos três; o que muda de um modelo para outro aparece marcado como frágil.
